# goit-js-hw-06

Домашнє завдання з JavaScript: контекст `this`, класи, приватні властивості й
методи об’єктів.

## Структура

- `js/task-1.js` — акаунт користувача: методи об’єкта `customer` з `this`.
- `js/task-2.js` — склад товарів: клас `Storage` із приватною властивістю `#items`.
- `js/task-3.js` — конструктор рядків: клас `StringBuilder` із приватною властивістю
  `#value`.

Відкрийте `index.html` у браузері та перегляньте результати виконання в
DevTools Console.
